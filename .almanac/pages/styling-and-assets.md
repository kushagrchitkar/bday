The app's visual behavior is defined by two CSS files and static font/image assets. `css/2bd23e4e59738440.css` contains Next-generated global reset rules and Inter font-face declarations [@global-css]. `css/b37c4cccb2fd38fb.css` contains the Custom Connections UI styles, including board layout, creator-form remnants, NYT-like font families, color mapping, modal behavior, and responsive rules [@app-css].

## Font And Brand-Like Styling

Application CSS declares `Franklin Light`, `Franklin`, `Franklin Bold`, and `Karnak Condensed` from local font files under [[fonts/]] [@app-css]. Headings use Karnak/Franklin combinations, board tiles use Franklin Bold, and game-title metadata uses Franklin Light [@app-css]. The global CSS also applies an Inter generated class to the body, but the app-specific selectors override it for the primary game UI [@global-css] [@app-css].

## Board Layout

The desktop board is a 632px-wide `.connections-wrapper`; each `.item` is 150 by 80 pixels with 4px margins, uppercase text, and a 6px radius [@app-css]. Completed rows are 624 by 80 pixels and use `.row-complete-wrapper.level-0` through `.level-3` for yellow, green, blue, and purple backgrounds [@app-css]. On screens up to 600px, the board becomes full width and tiles become 23% wide with 1% margins [@app-css].

The route emits these class names directly: `.item`, `.selected`, `.invalid-shake`, `.row-complete-wrapper level-N`, `.connections-wrapper`, `.mistakes-container`, `.buttons-wrapper`, `#toast`, `#popup`, and `.emoji` color classes [@route]. CSS changes to those names are behavior changes, not cosmetic-only edits.

## Modal And Icon

The results popup is an absolute full-page overlay with a white translucent backdrop and a centered `#popup-content` panel [@app-css]. The close affordance is `.close-x`, which uses `../images/icon-close.9326e13b.svg` as a CSS background image [@app-css] [@close-icon].

## Creator Styles Without Creator Route

The CSS includes styles for `.container`, `.instructions`, `.category-form-wrapper`, `.category-items-wrapper`, `.order-buttons`, `.author`, and `.game-link` [@app-css]. Those classes do not appear in the preserved `[slug]` route bundle, so they are evidence of a missing or separately bundled creator flow rather than active game-page code in this checkout.
